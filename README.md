# Eduardo Pereira — Portfólio

Portfólio React + TypeScript + Vite, em português e inglês.

## Executar

```bash
npm install
npm run dev
```

## Atualizar sem trocar o projeto inteiro

- Projetos, experiências, formação, certificações e recomendações: `src/data.ts`
- Textos gerais e componentes: `src/main.tsx`
- Aparência: `src/style.css`
- Imagens: `public/`

Apenas dois projetos pessoais são exibidos: Detecção de Fraude com Databricks e Credit Scoring. Os depoimentos são trechos fornecidos pelo titular, mantidos no idioma original. A imagem da DataCamp foi fornecida pelo titular; para outras certificações, adicione os arquivos a `public/certificates/` e preencha o campo `image` correspondente em `src/data.ts`. Links de validação não foram inventados.

A formação na UECE é exibida como trancada. O período da SoftDesign foi mantido até outubro de 2026 conforme solicitação do titular.

## Build

```bash
npm run build
```
